# ScreenBrief legal documents

This repository used to publish the ScreenBrief privacy policy at
<https://mattkent-cloud.github.io/screenbrief-legal/>. Since the site moved to
its own domain, that document is published on the site itself, in English and
Polish, at <https://screenbrief.app/privacy/>.

`index.html` is now a redirect to that address. It stays here because the
address was given to the Microsoft Store and appears in released builds, so it
has to keep working.

The source of truth is still `docs/privacy-policy.html` in the ScreenBrief
repository. Two published copies were one too many: they can disagree, and for
a document like this one disagreeing is the whole problem.
